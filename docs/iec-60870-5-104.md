# IEC 60870-5-104

IEC-104 is the TCP/IP profile of IEC 60870-5 telecontrol, the standard
SCADA protocol for electricity transmission and distribution in Europe, Asia
and much of the rest of the world. TCP port **2404**.

## APCI framing

Every APDU starts with `0x68`, a length byte and four control octets.

| Format | Detector | Purpose |
|---|---|---|
| **I** | bit 0 of octet 1 = 0 | carries an ASDU; holds send and receive sequence numbers |
| **S** | octets = `01 00 00 00` | supervisory acknowledgement of received I-frames |
| **U** | bits 0-1 = `11` | session control |

U-format functions: `STARTDT act` 0x07 / `con` 0x0B, `STOPDT act` 0x13 /
`con` 0x23, `TESTFR act` 0x43 / `con` 0x83.

`STARTDT` opens the monitored direction. **`STOPDT` closes it while leaving
TCP established** - the operator stops receiving measurements and events, but
the link still looks healthy. That is an elegant "inhibit response function"
primitive and is worth alerting on by itself.

Sequence numbers are 15-bit, shifted left by one in the control field
(`tx = (octet2 << 8 | octet1) >> 1`). Gaps or resets are a sign of injected
frames or a hijacked session.

## ASDU structure

```
type id (1) | VSQ (1) | cause of transmission (1) [+ originator] | common address (2) | information objects
```

- **VSQ**: bit 7 is SQ (sequence of objects sharing a start IOA), bits 0-6 the
  object count.
- **COT**: 1 periodic, 3 spontaneous, 5 request, **6 activation**,
  **7 activation confirmation**, 8 deactivation, 10 activation termination,
  20 interrogated by station. Bit 6 is **P/N** - set means *negative
  confirmation*: the device refused. Bit 7 marks a test frame.
- **Common address (CA)**: the station. **IOA**: 3 bytes, little-endian, the
  individual point.

## Type identifiers you will meet

Monitored direction: 1 `M_SP_NA_1` single point, 3 double point,
9/11 measured normalized/scaled, **13 `M_ME_NC_1` short float**, 30/31/36 the
same with CP56Time2a timestamps, 70 end of initialisation.

Control direction: **45 `C_SC_NA_1` single command**, 46 double command,
47 regulating step, 48/49 setpoint normalized/scaled, **50 `C_SE_NC_1`
setpoint short float**, 100 `C_IC_NA_1` interrogation, 101 counter
interrogation, 103 clock sync, **105 `C_RP_NA_1` reset process**.

Short floats are little-endian IEEE-754 on the wire - the opposite of S7comm.

## Select-before-operate

Command qualifier bit 7 (`S/E`) distinguishes **select** (1) from **execute**
(0). The compliant sequence for a controlled output is:

```
C_SC_NA_1 act (SELECT)  ->  act-con (SELECT)
C_SC_NA_1 act (EXECUTE) ->  act-con (EXECUTE)  ->  act-term
```

Two failure modes matter to a responder:

1. **Execute with no preceding select.** Either the device accepts
   direct-execute commands (many do) or an adversary is replaying a captured
   frame without understanding the handshake.
2. **Select never executed.** A point left selected can block legitimate
   operator commands - a quiet denial of control.

`iec104-triage.py --sbo` audits both, tracking only the activation direction
so the device's own confirmations do not create false positives.

## Command ordering and interlocks

A real plant sequence has an order: open the suction valve, confirm position,
start the pump, ramp the setpoint. Issue them out of order and the PLC's
interlocks trip the unit - which is exactly what "get the process running
without blowing anything up" challenges test. Read the IOA map first, work
out which points are feedback (monitored direction) and which are commands
(control direction), and drive the sequence off the feedback rather than off
fixed delays.

Rejections tell you where you broke an interlock: look for `act-con` with the
P/N bit set on the command you just sent.

## Hardening

- IEC-104 has no authentication. Where the equipment supports it, use
  **IEC 62351-3** (TLS for TCP profiles) or tunnel over a dedicated encrypted
  link; otherwise rely on strict segmentation and allow-listing.
- Alert on `STOPDT act`, `C_RP_NA_1` (reset process), clock sync from
  unexpected hosts, and any command from an IP that is not the master.
- Monitor sequence-number continuity per session.
- Review which points accept direct-execute; require select-before-operate on
  anything that moves plant.
